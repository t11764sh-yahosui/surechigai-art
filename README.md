# すれちがい美術展

図形カードで絵を描き、1人だけお題が違う「贋作師」を見破るオンラインパーティーゲーム。3〜8人、インストール不要・ブラウザだけで遊べます。

## 遊び方

1. 誰か1人が「新しい展覧会を開く」を押してホストになり、招待コード(または招待リンク)を仲間に送る
2. 仲間はコードを入れて入場。3人以上そろったらホストが開幕
3. 詳しいルールはゲーム内の「?」ボタンから

## しくみ

- `index.html` 1ファイルで動く静的ページ(ビルド不要)
- 通信は [PeerJS](https://peerjs.com/) による WebRTC の P2P。ホストのブラウザが進行役になり、ゲーム用のサーバーは不要
- 接続の仲介には PeerJS の無料公開サーバーを使用
